# Nour — Écoute du Coran

Application web mobile et installable pour lire et écouter le Coran avec plusieurs récitateurs.

## Publication avec GitHub Pages

1. Créez un dépôt public nommé `nour-quran` sur GitHub.
2. Envoyez le contenu de ce dossier vers la branche `main`.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, puis `main` et le dossier `/(root)`.
4. Votre application sera accessible à `https://VOTRE-IDENTIFIANT.github.io/nour-quran/`.

L’application est une PWA : une fois publiée en HTTPS, elle peut être installée depuis le navigateur mobile.
